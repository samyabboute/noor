# Zdjęcia produktów / Product photos

Umieść tutaj 3 zdjęcia Deglet Nour (białe tło studyjne). Kod odwołuje się do
**dokładnie tych nazw plików** — zachowaj je 1:1 :

| Plik | Zdjęcie | Gdzie się pojawia |
|------|---------|-------------------|
| `deglet-single.jpg` | pojedynczy daktyl | Galeria na stronie produktu (detal) |
| `deglet-trio.jpg`   | trzy daktyle | Sekcja „03 — Daktyl” + galeria produktu |
| `deglet-branch.jpg` | kiść na gałązce | Sekcja „04 — Rzemiosło” (zbiór, prosto z palmy) |

Zdjęcia na **białym tle** wtapiają się automatycznie w kremowe tło strony
(technika `mix-blend-multiply`) — nie trzeba wycinać tła.

## Jak dodać (bez klonowania repo)

1. GitHub → repozytorium `noor` → folder `public/products/`
2. **Add file → Upload files** → przeciągnij 3 zdjęcia
3. Nazwij je dokładnie jak w tabeli powyżej → **Commit**

Zalecane: format `.jpg`/`.webp`, ok. 1200×1500 px, < 300 KB każde.
Dopóki plików nie ma, w tych miejscach wyświetla się dyskretne kremowe pole
(strona się nie psuje).
